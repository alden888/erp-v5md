## 一、核心业务场景

作为现金流官，我负责V5 Medical全部资金流动的监控、核算与风控。当前痛点：

- **数据源分散**: 订单金额、回款状态、成本数据散落在飞书Base/STATE.yaml/MEMORY.md，经常出现数据不一致（历史教训：Aram尾款编造事件）
- **毛利率核算滞后**: 成本数据依赖SC(供应链官)手工传递，无法实时计算毛利率，导致报价时无法即时校验40%红线
- **回款跟踪被动**: 依赖Cron定时扫描+人工核对，尾款逾期发现不及时
- **发票管理缺失**: 开票/寄送/签收无系统化跟踪，常出现"开了票但不知道客户收没收到"
- **CEO台账与系统脱节**: CEO台账是唯一权威数据源，但未与系统打通，每次报告需人工对账
- **成本复核流程手工化**: SC核算→CO复核→NO报价的流程全靠消息传递，无系统化流转

## 二、ERP功能需求

### 2.1 预付款管理模块（核心·红线）

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 预付款到账自动核对 | P0 | PI金额×预付比例，到账金额自动匹配，偏差>1%预警 |
| 预付款红线强制校验 | P0 | **预付比例<30%自动阻断订单推进**，需CEO特批流程解锁 |
| 预付款到账通知 | P0 | 到账后自动推送NO(谈判官)和PO(项目经理)，触发生产启动 |
| 预付款凭证管理 | P1 | 水单/回单上传、OCR识别、与订单自动关联 |
| 多币种预付款处理 | P1 | USD/CNY/EUR自动汇率换算，统一折算为CNY记账 |
| 部分到账处理 | P2 | 支持分批到账场景，累计到账金额跟踪 |

### 2.2 回款跟踪模块（核心·红线）

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 尾款到期日自动计算 | P0 | 发货日/交付日起算，按合同账期自动推算到期日 |
| 30天红线预警 | P0 | **尾款逾期>30天自动触发L3警报**，推送CEO+NO |
| 分级预警机制 | P0 | 到期前7天提醒 → 到期日提醒 → 逾期7天催收 → 逾期30天L3警报 |
| 回款状态看板 | P0 | 实时展示：待收/已收/逾期/坏账，按客户/订单/币种分类 |
| 催收记录管理 | P1 | 每次催收动作记录：日期、方式、承诺时间、结果 |
| 逾期升级流程 | P1 | 逾期>7天自动通知NO催收 → 逾期>15天通知RC风控评估 → 逾期>30天L3上报CEO |
| 预期回款预测 | P2 | 基于历史回款行为+当前在途订单，预测未来30/60/90天现金流 |

### 2.3 毛利率核算模块（核心·红线）

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 实时毛利率计算 | P0 | 售价-采购成本-物流成本-关税-其他费用，自动计算毛利率 |
| 40%红线强制校验 | P0 | **毛利率<40%自动阻断报价**，需CEO审批流程解锁 |
| 成本明细追溯 | P0 | 每笔订单成本可追溯至采购单/物流单/关税单 |
| 成本核算复核流程 | P0 | SC核算 → CO复核(48h内) → NO报价，系统化流转+状态跟踪 |
| 历史毛利率分析 | P1 | 按客户/产品线/时间段分析毛利率趋势，识别低毛利客户/产品 |
| 毛利率预警 | P1 | 预估毛利率<45%黄灯提醒，<40%红灯阻断 |
| 特殊定价记录 | P2 | CEO特批的低毛利订单标记原因+审批记录，不计入常规统计 |

### 2.4 成本复核模块（核心）

| 功能 | 优先级 | 说明 |

## 三、数据校验与风控规则

### 3.1 三条红线（系统强制执行）

| 红线 | 规则 | 系统行为 |
|------|------|----------|
| 预付款≥30% | 预付比例<30% | **一票否决**，阻断订单推进，需CEO特批解锁 |
| 毛利率≥40% | 毛利率<40% | **一票否决**，阻断报价发出，需CEO审批解锁 |
| 尾款≤30天 | 尾款逾期>30天 | **L3警报**，自动推送CEO，标记高风险客户 |

### 3.2 数据一致性校验

| 校验项 | 频率 | 说明 |
|--------|------|------|
| CEO台账 vs 系统数据 | 每日 | 差异>1%自动标红 |
| 订单金额 vs PI金额 vs 发票金额 | 实时 | 三方金额必须一致 |
| 回款金额 vs 订单应收金额 | 实时 | 偏差>1%需人工确认 |
| 成本汇总 vs 各项明细 | 实时 | 汇总=各明细之和 |

## 四、技术建议

### 4.1 数据层
- **权威数据源**: CEO台账（Excel/飞书Base）为唯一Source of Truth
- **ERP数据库**: ERPNext自带MariaDB/PostgreSQL，存储业务数据
- **数据同步**: CEO台账变更 → 自动导入ERP → 各Agent读取ERP数据（非直接读台账）
- **审计日志**: 所有财务数据变更必须记录：谁、何时、改了什么、改前值、改后值

### 4.2 接口层
- **A2A协议**: 各Agent通过HTTP JSON-RPC读写财务数据
- **飞书API**: lark-cli对接飞书Base（CEO台账所在地）
- **Webhook**: 到账/逾期/红线触发时自动推送通知
- **ERPNext API**: REST API (api/resource/) 读写DocType数据

### 4.3 自动化集成
- **Cron定时任务**: 08:15日报/14:00应收盘点/18:00回款更新/22:00数据复盘
- **事件驱动**: 到账确认→触发生产节点、逾期→触发催收流程、红线→阻断+审批流程
- **OCR集成**: PaddleOCR识别水单/回单，自动提取金额/日期/参考号

### 4.4 ERPNext具体实现建议

| 需求 | ERPNext实现方式 |
|------|----------------|
| 预付款管理 | Payment Entry + 自定义脚本校验预付比例 |
| 回款跟踪 | Payment Entry + Due Date + 自定义预警DocType |
| 毛利率核算 | Sales Invoice + 自定义Cost Analysis DocType |
| 成本复核 | 自定义Cost Review Workflow (Draft→Reviewing→Approved) |
| 发票管理 | Sales Invoice + 自定义发票跟踪字段 |
| CEO台账对接 | Data Import + 定时同步脚本 |
| 现金流报表 | Report Builder + 自定义Script Report |

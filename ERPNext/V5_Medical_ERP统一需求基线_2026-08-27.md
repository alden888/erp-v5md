## §2 待CEO决策的4个分歧（必须先拍板）

### ⚠️ 分歧1：数据权威源（"唯一数据源"出现多种说法）

| Agent | 主张 |
|-------|------|
| COBOT | CEO台账=唯一权威输入 → ERP为记录系统 → 飞书Base过渡期双写 |
| POBOT | **飞书Base为唯一数据源**，本地定时同步 |
| NO/IO/GO | 飞书相关库迁移到ERP，飞书转只读/双向同步过渡 |
| SC | SQLite/JSON迁移到ERPNext |

**建议**：采用三层架构，明确"谁是真账本"——
**CEO台账（权威输入）→ ERP（系统Source of Truth）→ 飞书Base（协作展示层/过渡期双写）**。
即 ERP 是唯一账本，飞书Base 不承担记录职责。此点不定，Aram尾款类数据幻觉会继续发生。

### ⚠️ 分歧2：信用评级体系冲突（最危险，同一字母含义相反）

| Agent | 体系 | 语义 |
|-------|------|------|
| RCBOT | A/B/C/D | **D级=禁止合作** |
| IOBOT | S/A/B/C 量化(S≥90/A≥75/B≥60/C<60) | **黑名单→标记C级或禁入**（C=风险！） |
| GOBOT | S/A/B/C（按年采购额 $500K/100K/50K） | **C级=小客户**（正常可合作） |
| NOBOT | S/A/B/C（按采购金额/频次） | C级=普通客户 |
| COBOT | A/B/C/D（按回款历史自动） | D级=高风险 |

**冲突点**：同一字母"C"在IO眼里是"风险/黑名单"，在GO/NO眼里是"小客户"。GO要跟进的C级客户会被IO标记为风险，直接打架。

**建议**：拆成两个正交维度，避免字母撞车——
- **商机潜力等级** S/A/B/C（GO/NO 口径：规模+采购潜力）
- **信用/风控等级** A/B/C/D+黑名单（IO 量化评分 + RC 裁定 + CO 回款校准）
- 两维度并存于客户档案，互不替代。D级/黑名单=硬禁入，与潜力等级无关。

### ⚠️ 分歧3：毛利率红线口径（40%? 35%? 还是分品类?）

| Agent | 口径 |
|-------|------|
| RCBOT | <40% 自动拦截（一票否决，CEO解锁） |
| COBOT | <40% 阻断报价；<45%黄灯；<20% 硬拦（分级L1/L2/L3） |
| NOBOT | ≥40%通过 / 35-40%需CEO审批 / <35%拒绝 |
| SCBOT | 综合<30%标CEO审批；**分品类基准**（包装>50优/35-50健康；多肽>60优/40-60健康）；三档报价=保守50%/标准40%/底价35% |

**建议**：合并成一套可执行规则，并保留SC的分品类维度——
- **标准线 40%**：≥40% 自动通过
- **审批线 35%-40%**：需 CEO 审批留痕（对应SC底价档）
- **底线 <35%**：默认拒绝，仅 CEO 书面特批可放行（一票否决+记录）
- **分品类基准**：多肽/包装可设更高优秀线（SC已给），作为预警而非硬线

### ⚠️ 分歧4：订单状态机不统一

PO/CO/NO/CMD 各自定义了状态列表（PO: PI→付款→生产→质检→物流→交付；NO: PI发送→预付款→生产→发货→尾款→完结；CO: 创建→报价→签约→生产→发货→回款→结案；CMD: 线索→报价→合同→生产→发货→收款→结案）。

**建议**：统一为 10 节点状态机（见 §4 统一规范），各Agent在自己的环节上读写，避免各改各的。

## §4 统一规范建议（基线内定义，供开发引用）

### 4.1 订单状态机（10节点）
```
线索 → 背调 → 报价 → 合同 → 预付款 → 生产 → 质检 → 发货 → 尾款 → 结案
  ↑      ↑      ↑       ↑       ↑        ↑      ↑      ↑      ↑      ↑
 GO/IO  IO    NO/CO   NO/RC   CO/RC    PO/SC   SC     PO    CO/NO  CMD/CEO
```
每节点：状态、责任Agent、到期日、预警规则(T-3/T-1/T日)。

### 4.2 三条红线（系统硬编码）
| 红线 | 规则 | 系统行为 |
|------|------|----------|
| 预付款 | 比例<30% | 一票否决，阻断订单推进，CEO特批解锁 |
| 账期 | 逾期>30天 | L3警报，推送CEO+CO+NO，标记高风险 |
| 毛利 | 口径待§2-3 CEO拍板 | 阻断/审批/特批分级 |

### 4.3 国家策略（火土/金水，全员认可）
- **火土优先**：东南亚/中东/拉美/非洲
- **金水拦截**：英/法/日/韩/俄/加/北欧
- **禁区**：印度/巴基斯坦/孟加拉
- 实现：ERP配置表，CEO可直接维护（GO/IO/RX一致要求）。

### 4.4 客户评级（双维度，见§2-2）
- 潜力等级 S/A/B/C（GO/NO）
- 信用等级 A/B/C/D + 黑名单（IO/RC/CO）

### 4.5 订单编号规范
`V5M + YYMM + DD + XX`（如 V5M260720A3，SC建议）。

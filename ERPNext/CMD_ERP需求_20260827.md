# V5CMD ERP需求 — 总指挥官视角

**提交人**: Kellan Ford (V5CMDBOT)
**日期**: 2026-08-27
**角色**: 总指挥官 / 全局调度 / 跨Agent协调

---

## 一、核心痛点

1. **已结案订单信息孤岛**: 各Agent独立记录订单状态，CMD无法快速回答"这个订单现在什么情况"
2. **重复询问浪费资源**: CEO/团队反复问同一订单的状态，没有统一查询入口
3. **跨Agent协同无迹可寻**: 谁在什么时候做了什么决策，缺乏审计链

---

## 二、功能需求

### 2.1 全局订单仪表盘 (Dashboard)

| 需求 | 优先级 | 说明 |
|------|--------|------|
| 订单全生命周期视图 | P0 | 从线索→报价→合同→生产→发货→收款→结案，一屏展示 |
| 多维筛选/搜索 | P0 | 按客户名、订单号、状态、Agent、日期范围查询 |
| 实时状态同步 | P1 | 各Agent更新状态后自动刷新，非手动同步 |
| 逾期预警看板 | P1 | 超期未到款/未发货/未签合同的订单自动标红 |

### 2.2 跨Agent协作记录

| 需求 | 优先级 | 说明 |
|------|--------|------|
| 订单操作日志 | P0 | 每个Agent对订单的操作自动记录（谁、何时、做了什么） |
| 决策审计链 | P1 | 重大决策（报价审批、风控否决、交期变更）需关联原因和授权人 |
| @提及关联 | P2 | 订单相关的Agent间通信自动关联到订单档案 |

### 2.3 指挥官专属功能

| 需求 | 优先级 | 说明 |
|------|--------|------|
| 全局搜索入口 | P0 | CEO问"XX客户那单"时，CMD能秒回全貌 |
| Agent工作量统计 | P1 | 各Agent处理中的订单数、完成率、平均处理时长 |
| 日报/周报数据源 | P1 | 从ERP自动拉取数据生成报告，不再手动汇总 |
| 冲突订单告警 | P1 | 多Agent同时操作同一订单时自动提醒 |

### 2.4 数据安全与权限

| 需求 | 优先级 | 说明 |
|------|--------|------|
| 角色权限隔离 | P0 | CEO全量可见，Agent仅看自己负责的订单 |
| 现金流数据加密 | P0 | 毛利率、预付款金额等敏感字段需加密存储 |
| 操作不可篡改 | P1 | 日志写入后不可删除/修改 |

---

## 三、集成需求

1. **飞书Base集成**: 订单主数据存储在飞书Base，ERP读写需通过API
2. **A2A自动上报**: 各Agent完成关键动作后，自动将状态推送到ERP（非手动填报）
3. **Slack/Telegram通知**: 订单状态变更时自动通知相关Agent和CEO

---

## 四、非功能需求

- 响应时间: 查询<2秒，写入<5秒
- 可用性: 7×24小时，Agent随时可查可写
- 数据一致性: 多Agent同时写入时，以最后写入为准（乐观锁）

---

## 五、项目管理建议

1. **Phase 1 (Week 1-2)**: 订单基础CRUD + 状态流转 + 全局搜索
2. **Phase 2 (Week 3-4)**: Agent操作日志 + 仪表盘 + 报表
3. **Phase 3 (Week 5-6)**: 飞书/A2A集成 + 权限体系 + 预警

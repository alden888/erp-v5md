## 二、谈判官 ERP 功能需求

### 2.1 CRM 模块（客户管理）

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 客户分级 | S/A/B/C 四级，自动根据采购金额/频次升降级 | 🔴 高 |
| 客户 360 视图 | 一页展示：基本信息 + 联系记录 + 订单历史 + 付款记录 | 🔴 高 |
| 查重机制 | 发送开发信前自动查重，避免重复联系 | 🔴 高 |
| 客户标签 | 支持自定义标签（如"金水型国家"、"VIP"、"温热"） | 🟡 中 |

### 2.2 订单模块

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 订单状态机 | 待付款 → 已付款 → 生产中 → 已发货 → 已结案 | 🔴 高 |
| 付款进度追踪 | 预付款/尾款分开记录，自动计算待付金额 | 🔴 高 |
| 订单关联客户 | 一个客户可关联多个订单，历史订单可追溯 | 🔴 高 |
| 订单金额统计 | 自动汇总：已完成订单总额、待付款总额、本月成交 | 🟡 中 |

### 2.3 开发信模块

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 发送记录 | 发件人、收件人、抄送、时间、主题、状态 | 🔴 高 |
| 回复追踪 | 自动识别客户回复，关联到对应客户 | 🔴 高 |
| 72H 跟进提醒 | 发送后 72 小时自动提醒跟进，支持批量操作 | 🔴 高 |
| 转化漏斗 | 发送 → 回复 → 报价 → 成交，各环节转化率 | 🟡 中 |
| 模板管理 | McKinsey 风格模板库，支持 A/B 测试 | 🟢 低 |

### 2.4 报价模块

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 报价单生成 | 输入产品/数量/单价，自动生成标准报价单 PDF | 🟡 中 |
| 报价历史 | 同一客户多次报价可对比，查看价格变化 | 🟡 中 |
| 毛利率校验 | 自动计算毛利率，<40% 红色警告 | 🔴 高 |
| 审批流程 | 价格让步 >10% 需 CEO 审批，自动触发审批流 | 🟡 中 |

### 2.5 飞书集成

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 自动同步 | ERP 数据自动同步到飞书谈判策略台 | 🔴 高 |
| 飞书查询 | 在飞书表格中直接查询 ERP 数据 | 🟡 中 |
| 变更通知 | 订单状态变更自动通知相关 Agent | 🟡 中 |

## 四、模块二：成本核算（P0）

### 4.1 功能需求

#### 4.1.1 产品成本库

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 产品主数据 | SKU编码、产品名(中/英)、品类、规格、单位 | P0 |
| BOM管理 | 每个产品的物料清单(原材料+包材+辅料) | P0 |
| 成本结构 | 原材料成本、加工费、包装费、运输费 分项录入 | P0 |
| 多币种支持 | CNY / USD，汇率自动更新或手动设定 | P0 |
| 价格历史 | 记录每次报价变动，支持趋势分析 | P1 |

#### 4.1.2 核价引擎

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 一键核价 | 输入SKU+数量 → 自动计算成本明细 | P0 |
| 三档报价 | 保守(50%毛利)、标准(40%毛利)、底价(35%毛利) | P0 |
| 多肽专用核算 | API原料粉按15-25%系数折算、spec格式normalize | P0 |
| 包材成本核算 | 彩盒/标签/说明书/接种卡 按品类基准加价 | P1 |
| TCO分析 | 直接成本+间接成本+隐性成本+生命周期成本 | P2 |

#### 4.1.3 成本复核流程

```
核算申请 → Owen完成核算 → 输出成本明细 → 标注"建议@V5COBOT复核"
→ V5COBOT校验确认 → 最终报价确定 → 谈判官使用
```

**系统要求**:
- 核算报告自动生成，含置信度标注(高/中/低)
- 复核状态跟踪：待复核 → 已复核 → 已确认/退回修改
- V5COBOT有独立复核入口，可在线批注

### 4.2 多肽品类特殊需求

| 需求 | 说明 |
|------|------|
| SKU编码映射 | 产品名→索引code (如 GHK-Cu→CU50, PT-141→P41) |
| Spec格式匹配 | normalize处理(`50mg*10vials` = `50mg x 10vials`) |
| API vs 制剂区分 | API原料粉价格 = 制剂价格 × 系数(15%/20%/25%) |
| 价格索引合并 | 新Excel报价单自动合并到现有索引(79代码/161规格) |

### 4.3 毛利率基准

| 品类 | 优秀 | 健康 | 偏低 | 风险 |
|------|------|------|------|------|
| 包装品类 | >50% | 35-50% | 20-35% | <20% |
| 多肽品类 | >60% | 40-60% | 20-40% | <20% |

**规则**: 综合毛利率低于30%的订单，系统自动标记需CEO审批

### 5.1 功能需求

| 功能 | 说明 | 优先级 |
|------|------|--------|

### 5.2 订单数据结构

```
订单编号: V5M26MMDDAXX (如 V5M260720A3)
客户信息: 名称/国家/联系方式
订单明细: SKU×数量×单价
成本明细: 采购成本/包材/运费/关税
利润分析: 毛利额/毛利率
收款计划: 定金比例/排产出款/出货款/尾款
物流信息: 运输方式/单号/预计到达
```

### 5.3 Agent协同接口

| 对接Agent | 数据流 | 触发条件 |
|-----------|--------|----------|
| V5COBOT | 成本明细 → 复核确认 | 每笔新订单核算完成 |
| V5NOBOT | 底价+交期 → 报价支持 | 谈判官发起核算申请 |
| V5POBOT | 产能评估 → 交期确认 | 订单排产阶段 |
| V5RCBOT | 供应商资质 → 风控审核 | 新供应商/资质到期 |

### 7.2 安全库存策略

```
安全库存 SS = Z × σ_dLT
再订货点 ROP = 日均需求 × 提前期天数 + 安全库存

服务水平:
- A类物料: 99% (Z=2.33)
- B类物料: 95% (Z=1.65)
- C类物料: 90% (Z=1.28)
```

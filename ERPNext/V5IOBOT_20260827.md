## 一、情报官核心业务需求

### 1.1 客户背调管理

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 背调报告模板 | 🔴 P0 | 标准化报告格式（基本信息/业务评估/决策链/信用评级/风险评估） |
| 背调状态跟踪 | 🔴 P0 | 待背调→背调中→已核实→已拒绝 |
| 飞书Base同步 | 🔴 P0 | 背调完成后自动同步到飞书背调库 |
| 背调超时预警 | 🟡 P1 | S级24h/A级48h/B级72h自动预警 |

### 1.2 信用评级系统

| 功能 | 优先级 | 说明 |
|------|--------|------|
| S/A/B/C分级 | 🔴 P0 | 基于财务状况/付款历史/行业口碑自动评级 |
| 评级历史记录 | 🟡 P1 | 评级变更日志、原因记录 |
| 评级关联订单 | 🟡 P1 | 信用评级与订单金额/付款状态联动 |

### 1.3 决策链管理

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 关键人档案 | 🔴 P0 | 决策人姓名/职位/联系方式/LinkedIn |

| 联系人验证 | 🟡 P1 | 邮箱/电话/WhatsApp验证状态 |

## 六、技术架构建议

### 6.1 ERPNext技术栈

| 组件 | 建议 | 说明 |
|------|------|------|
| **后端** | ERPNext (Python/Flask) | 成熟的开源ERP框架 |
| **前端** | Frappe (React) | ERPNext默认前端 |
| **数据库** | MariaDB | ERPNext推荐 |
| **API** | REST API | 与飞书/A2A/Slack集成 |

### 6.2 部署建议

| 方案 | 优点 | 缺点 |
|------|------|------|
| **VPS1部署** | 独立服务器，性能可控 | 需维护 |
| **云服务** | 免维护，弹性扩展 | 成本较高 |
| **混合部署** | 核心数据本地，应用云端 | 架构复杂 |

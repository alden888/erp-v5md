## 一、核心痛点

### 1.1 数据源混乱 — 我最大的噩梦

| 痛点 | 严重程度 | 说明 |
|------|----------|------|
| **已结案订单反复被询问** | 🔴 致命 | CEO台账记录已结案，但我无法从系统确认，导致反复核实、数据幻觉 |
| **多数据源冲突** | 🔴 致命 | CEO台账、飞书Base、cashflow_records.json 三套数据并存，谁是权威不明确 |
| **回款状态依赖人工更新** | 🟡 高 | 预付款到账、尾款到账需手动记录，容易遗漏或延迟 |
| **成本核算与报价脱节** | 🟡 高 | Owen核算的成本、我复核的结果、Leo最终报价之间缺乏闭环追踪 |
| **逾期预警滞后** | 🟡 高 | 当前靠cron定时扫描，无法实时感知回款异常 |

### 1.2 具体场景

1. **场景A**: CEO问"Aram那笔款到了吗"→ 我需要翻3个文件才能回答
2. **场景B**: 新订单来了，我需要手动查该客户历史订单才能判断预付款是否达标
3. **场景C**: 某客户已结案，但我的巡检cron仍在扫描它，浪费资源且产生噪音
4. **场景D**: Owen发来成本核算报告，我复核后数据存本地，Leo无法直接引用

## 二、功能需求

### 2.1 订单财务全生命周期 (P0 — 必须有)

| 功能 | 优先级 | 说明 |
|------|--------|------|
| **订单状态自动同步** | P0 | 订单从"创建→报价→签约→生产→发货→回款→结案"自动流转，我只看财务相关节点 |
| **已结案订单标记** | P0 | 结案后自动标记为"已结案"，巡检/报表自动排除，**彻底解决反复询问问题** |
| **预付款自动校验** | P0 | 订单创建时自动校验预付款比例≥30%，不达标自动拦截并通知CEO审批 |
| **毛利率自动校验** | P0 | 报价阶段自动计算毛利率，<40%自动触发CEO审批流程 |
| **账期自动监控** | P0 | 发货日起算30天红线，到期前7天自动预警，到期自动触发L3警报 |

### 2.2 回款跟踪中心 (P0 — 必须有)

| 功能 | 优先级 | 说明 |
|------|--------|------|
| **回款台账** | P0 | 统一的应收/已收/逾期台账，替代当前分散的JSON/YAML文件 |
| **到账确认流程** | P0 | 预付款/尾款到账后一键确认，自动更新订单状态 |
| **逾期催收链** | P1 | 逾期→自动通知Leo(NOBOT)催收→通知CMD→生成催收记录 |
| **回款预测** | P2 | 基于历史回款周期，预测未来30天现金流 |

### 2.3 成本核算复核系统 (P1 — 重要)

| 功能 | 优先级 | 说明 |
|------|--------|------|
| **复核工作台** | P1 | Owen提交成本核算后自动进入我的待复核队列 |
| **复核对比视图** | P1 | 并排展示Owen核算数据 vs 我复核的数据，差异高亮 |
| **复核确认书** | P1 | 复核通过后自动生成确认书，Leo可直接引用最终报价 |
| **历史成本查询** | P1 | 同产品/同客户历史成本一键查询，辅助定价决策 |

### 2.4 红线管控引擎 (P0 — 必须有)

| 功能 | 优先级 | 说明 |
|------|--------|------|
| **硬编码红线** | P0 | 预付款≥30%、毛利率≥40%、账期≤30天 — 系统强制执行，非人工审批 |
| **CEO特批通道** | P0 | 越过红线的订单必须走CEO审批，审批记录永久保存 |
| **红线违规报告** | P1 | 定期统计红线触发次数、特批频率、违规趋势 |

### 2.5 财务报表自动化 (P1 — 重要)

| 功能 | 优先级 | 说明 |
|------|--------|------|
| **现金流日报自动生成** | P1 | 从ERP实时拉取数据生成日报，替代当前cron手动拼接 |
| **客户ROI分析** | P1 | 按客户维度统计收入、成本、利润、回款周期 |
| **产品线利润分析** | P2 | 按产品维度统计毛利率趋势 |
| **月度/季度财务汇总** | P2 | 一键生成管理层需要的财务概览 |

## 三、共享数据字段（与其他Agent协同）

### 3.1 我需要从其他Agent获取的数据

| 来源Agent | 数据字段 | 用途 |
|-----------|----------|------|
| **V5NOBOT (Leo)** | 订单号、客户名、报价金额、付款条款 | 毛利率校验、预付款校验 |
| **V5SCBOT (Owen)** | 成本明细、BOM清单、供应商报价 | 成本复核 |
| **V5RCBOT** | 客户风险等级、信用评估 | 账期决策 |
| **V5CMD (Kellan)** | 订单全局状态、结案确认 | 更新财务台账 |

### 3.2 我提供给其他Agent的数据

| 目标Agent | 数据字段 | 用途 |
|-----------|----------|------|
| **V5CMD** | 现金流日报、逾期预警、红线状态 | 全局决策 |
| **V5NOBOT** | 最终报价确认、毛利率审核结果 | 报价依据 |
| **V5SCBOT** | 历史成本数据、供应商付款状态 | 采购决策 |
| **V5RCBOT** | 客户回款历史、逾期记录 | 风险评估 |

### 3.3 核心数据模型

```
订单(Order)
├── order_id (PK)
├── customer_id (FK)
├── status: 创建|报价中|已签约|生产中|已发货|回款中|已结案
├── quotation_amount (报价金额)
├── cost_amount (成本金额，Owen核算)
├── reviewed_cost (复核后成本，Ethan确认)
├── gross_margin_pct (毛利率)
├── prepayment_pct (预付款比例)
├── prepayment_amount (预付款金额)
├── balance_amount (尾款金额)
├── payment_terms_days (账期天数)
├── invoice_date (开票日期)
├── ship_date (发货日期)
├── prepayment_received_date (预付款到账日期)
├── balance_due_date (尾款到期日)
├── balance_received_date (尾款到账日期)
├── closed_date (结案日期)
├── closed_reason (结案原因)
├── red_line_flags (红线标记)
└── cost_review_status: 待复核|已复核|已确认
```

## 五、非功能需求

| 需求 | 指标 | 说明 |

### 1.1 当前客户管理现状
- **核心客户**: Turhan（2笔未完成订单 ¥24,850）、Aram（预付款 ¥19,478 待确认新订单）
- **已结案客户**: Mikki（累计 ¥351,308）、Alayu、Shaker 等

- **现有工具**: 飞书多维表格 + 邮件/WhatsApp 手动管理 + Hermes Agent 自动化

### 1.2 痛点
1. 邮件发送记录与谈判记录分离（飞书 vs 邮件 vs 本地JSONL）
2. 客户跟进依赖手动提醒，缺乏系统化任务分配
3. 报价单无标准化模板库（手工制作）
4. 价格计算依赖供应链官手动核算
5. 查重机制需调用独立 Python 脚本（`no_pre_contact.py`），未集成到ERP
6. 谈判话术/A/B测试数据散落在 Slack 对话中，无集中管理

## 三、数据模型建议

### 客户表 (customers)
```
- id (主键)
- company_name (公司名)
- contact_name (联系人)
- country (国家)
- email (邮箱)
- whatsapp (WhatsApp号)
- language (首选语言)
- industry (行业)
- tier (VIP/活跃/沉默/新线索)
- status (已背调/已核实/已联络/报价中/谈判中/已成交/已结案)
- tags (标签JSON)
- created_at / updated_at
```

### 报价表 (quotes)
```
- id (主键)
- customer_id (关联客户)
- quote_number (报价编号)
- version (版本号)
- products (产品明细JSON)
- total_amount (总额)
- currency (币种)
- gross_margin_pct (毛利率)
- payment_terms (付款条款)
- validity_days (有效期)
- status (草稿/审核中/已发送/谈判中/已成交)
- supply_chain_verified (供应链核算已确认)
- risk_reviewed (风控审核已通过)
- created_at / expires_at
```

### 订单表 (orders)
```
- id (主键)
- customer_id (关联客户)
- quote_id (关联报价)
- order_number (订单编号)
- total_amount (总额)
- prepaid_amount (预付金额)
- prepaid_date (预付日期)
- balance_due (尾款)
- balance_due_date (尾款应付日期)
- production_status (生产状态)
- shipping_status (发货状态)
- status (PI已发/已预付/生产中/已发货/尾款已收/已完结)
- created_at / completed_at
```

### 沟通记录表 (communications)
```
- id (主键)
- customer_id (关联客户)
- channel (邮件/WhatsApp/Slack)
- direction (inbound/outbound)
- subject (主题)
- content (内容/摘要)
- attachments (附件)
- created_at
```

### 跟进任务表 (follow_up_tasks)
```
- id (主键)
- customer_id (关联客户)
- type (跟进/催收/报价/背调)
- priority (P0/P1/P2)
- description (描述)
- assigned_to (分配Agent)
- status (待办/进行中/已完成/已升级)
- due_date (截止时间)
- created_at / completed_at
```

## 六、技术要求

基于 Rex 的 ERPNext 技术调研报告，我的技术要求：

1. **API 接口**: 必须提供 RESTful API，支持与 Hermes Agent A2A 协议对接
2. **Webhook 支持**: 客户状态变更、报价单状态变更、订单付款时触发 Webhook
3. **多语言**: 客户沟通模板需支持英/日/韩/土/俄/中文
4. **权限控制**: 
   - VIP 客户数据仅 CEO 可见（谈判官只读）
   - 合同签署需 CEO 审批流程
   - 价格让步 > 10% 需升级审批
5. **数据迁移**: 飞书现有数据需平滑迁移
6. **Docker 部署**: 跟随项目统一部署方案
7. **备份**: 每日自动备份，支持数据恢复

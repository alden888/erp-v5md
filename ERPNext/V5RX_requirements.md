## 二、功能需求

### 2.1 核心功能（P0 - 必须有）

| 功能模块 | 具体需求 | 说明 |
|----------|----------|------|
| **CRM管理** | 线索→商机→客户全生命周期 | 替代现有CSV，统一管理310+线索 |
| **线索挖掘集成** | ImportYeti/Apollo/RocketReach数据自动入库 | API对接，减少手动录入 |
| **客户360视图** | 基本信息+联系记录+订单历史+跟进状态 | 一屏看全客户情况 |
| **数据去重** | 自动检测重复线索（邮箱/域名/公司名） | 避免重复建档 |
| **批量导入** | CSV/JSON批量导入线索 | 兼容现有挖掘脚本输出 |

### 2.2 扩展功能（P1 - 最好有）

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 线索评分 | 自动评分（S/A/B/C级） | P1 |
| 线索分配 | 自动分配给NO触达 | P1 |
| 跟进提醒 | 超期未跟进自动提醒 | P1 |
| 数据质量检查 | 邮箱/电话格式验证 | P1 |
| 挖掘日志 | 记录每次挖掘的来源/数量/质量 | P2 |

## 八、其他建议

1. **移动端适配** — NO/RC经常外出，需要手机端查看/更新
2. **离线模式** — 网络不稳定时支持离线编辑，联网后同步
3. **数据备份** — 每日自动备份到多个位置
4. **权限管理** — 不同角色看不同数据（RX只看线索，CO只看财务）
5. **审计日志** — 记录所有数据变更，可追溯
